Backend Engineer (2–4 years) — Bengaluru, hybrid

- Write unit and integration tests; review code; keep CI green.

Must have
- Strong data structures and algorithms (hash maps, sorting, two pointers, basic graphs).
- 2+ years building REST APIs in Python or Node.js.
- PostgreSQL: schema design, indexing, transactions.
- Git and code review habits.

Nice to have

- Experience with payments, UPI or reconciliation.
